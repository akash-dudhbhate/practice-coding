# Capstone Project 01 — Personal Portfolio Website

> **Type:** Capstone Project
> **Subject:** HTML/CSS/JS
> **Estimated sell price:** $500–1000
> **Difficulty:** Advanced
> **Prerequisites:** All 20 HTML/CSS/JS lessons

## Project Brief

Build a complete, production-ready personal portfolio website. This is a sellable product — many freelancers, developers, designers, and consultants need portfolio sites. The site must be responsive, accessible, animated, and have a dark mode toggle.

## What you'll build

A multi-section single-page portfolio:
- **Hero** — name, title, tagline, CTA buttons (View Work, Contact)
- **About** — bio, skills with progress bars or tags
- **Projects** — grid of project cards with images, descriptions, links
- **Experience** — timeline of work history
- **Contact** — form with validation (name, email, message)
- **Footer** — social links, copyright
- **Dark mode toggle** — persists in localStorage
- **Smooth scroll** navigation
- **Scroll animations** — sections fade in as you scroll
- **Mobile menu** — hamburger menu for mobile

## Skills you'll demonstrate

- Semantic HTML5 structure
- CSS Flexbox + Grid layout
- CSS animations and transitions
- CSS variables for theming (dark mode)
- Responsive design (mobile-first)
- JavaScript DOM manipulation
- JavaScript event handling
- localStorage for theme persistence
- Form validation
- Accessibility (ARIA, keyboard nav, alt text)

## Sellable pitch

> "I'll build you a stunning, professional portfolio website that showcases your work and helps you land clients or jobs. Features include dark mode, smooth animations, responsive design, contact form, and SEO optimization. You'll get a site that loads fast and looks amazing on any device."

## Requirements

- [ ] Hero section with name, title, and CTA buttons
- [ ] About section with bio and skills
- [ ] Projects section with 4–6 project cards (image, title, description, link)
- [ ] Experience timeline (vertical timeline with dates)
- [ ] Contact form with client-side validation
- [ ] Dark mode toggle (button in nav, persists in localStorage)
- [ ] Smooth scrolling navigation
- [ ] Scroll-triggered animations (Intersection Observer API)
- [ ] Mobile hamburger menu
- [ ] Fully responsive (320px to 1920px)
- [ ] Accessible (keyboard navigation, ARIA, alt text, skip link)
- [ ] SEO meta tags (title, description, Open Graph)
- [ ] Fast loading (optimized images, minimal dependencies)
- [ ] Clean, modern design with consistent spacing and typography

## Getting started

1. Plan your sections and sketch the layout.
2. Write the HTML structure (semantic tags).
3. Add CSS — start with variables (colors, spacing), then layout, then components.
4. Implement dark mode with CSS variables and JS toggle.
5. Add scroll animations with Intersection Observer.
6. Build the mobile menu.
7. Add form validation.
8. Test accessibility (keyboard, screen reader, Lighthouse).
9. Optimize images and test performance.
10. Deploy (GitHub Pages, Netlify, Vercel — all free).
