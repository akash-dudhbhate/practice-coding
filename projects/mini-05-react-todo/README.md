# Mini Project 05 — React Todo App

> **Type:** Mini Project
> **Subject:** React
> **Estimated sell price:** $100–200
> **Difficulty:** Beginner
> **Prerequisites:** Lessons 01–05 (React Core: Components, State, Events, Conditional, Lists)

## Project Brief

Build a classic todo app with React — add, complete, delete, and filter tasks. This is the "Hello World" of React apps and a must-have portfolio piece.

## What you'll build

- Add new todo (input + button)
- Mark todo as complete (checkbox/strikethrough)
- Delete todo (X button)
- Filter: All / Active / Completed
- Task counter ("3 items left")
- Clear completed button
- Empty state message

## Skills you'll demonstrate

- useState for todo list and filter
- Event handling (onClick, onChange, onSubmit)
- Conditional rendering (empty state, filter views)
- Lists and keys (.map with key)
- Immutable state updates (spread operator)

## Requirements

- [ ] Add todo: input field + Add button, Enter key also works
- [ ] Each todo: text, completed status, delete button
- [ ] Click todo text to toggle completed (strikethrough style)
- [ ] Filter buttons: All, Active, Completed
- [ ] Counter shows remaining active tasks
- [ ] "Clear completed" button removes all completed todos
- [ ] Empty state: "No todos yet" when list is empty
- [ ] Input clears after adding
- [ ] No empty todos (don't add if input is blank)
- [ ] Clean, simple design

## Deliverables

- Single React component (or 2-3 components)
- Works in browser
- Clean, minimal styling
