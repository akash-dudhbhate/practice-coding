# Mini Project 02 — Landing Page with Flexbox

> **Type:** Mini Project
> **Subject:** HTML/CSS/JS
> **Estimated sell price:** $100–200
> **Difficulty:** Beginner–Intermediate
> **Prerequisites:** Lessons 01–10 (HTML + CSS through Flexbox)

## Project Brief

Build a modern, responsive landing page for a fictional product or service. The page uses CSS Flexbox for all layout — no floats, no tables, no grid (Flexbox only). This is a common freelance deliverable for small businesses, startups, and personal brands.

## What you'll build

A single-page landing with:
- **Hero section** — headline, subheadline, CTA button, background image/gradient
- **Features section** — 3–4 feature cards in a flex row (wraps on mobile)
- **Testimonial section** — centered quote with author
- **Pricing teaser** — 3 pricing cards (highlighted middle card)
- **Footer** — links, social icons, copyright
- Fully responsive (mobile-first, flex-wrap for cards)

## Skills you'll demonstrate

- CSS Flexbox (justify-content, align-items, flex-wrap, gap, flex-direction)
- Responsive design (media queries, mobile-first)
- CSS Box Model (margin, padding, box-sizing)
- CSS Typography (font sizes, line-height, colors)
- Semantic HTML structure

## Sellable pitch

> "I'll design and build a modern, responsive landing page for your product. It loads fast, looks great on mobile and desktop, and uses the latest CSS Flexbox for perfect alignment. Includes hero, features, testimonials, and pricing sections."

## Requirements

- [ ] Hero section with headline, subheadline, and CTA button
- [ ] Features section with 3–4 cards using Flexbox (flex-wrap on mobile)
- [ ] Testimonial section with centered content
- [ ] Pricing section with 3 tiers (middle one highlighted)
- [ ] Footer with links and copyright
- [ ] All layout uses Flexbox (no floats, no position for layout)
- [ ] Responsive: mobile shows single column, desktop shows multi-column
- [ ] Uses `box-sizing: border-box` globally
- [ ] Clean, professional color scheme (use CSS variables for colors)
- [ ] Smooth hover effects on buttons and cards

## Getting started

1. Plan your layout — sketch the sections on paper.
2. Write the HTML structure (semantic tags).
3. Add CSS reset/normalize and `box-sizing: border-box`.
4. Build each section with Flexbox, starting mobile-first.
5. Add media queries for tablet and desktop.
6. Polish: colors, typography, hover effects, transitions.
7. Test on mobile, tablet, and desktop widths.

## Deliverables

- `index.html` + `styles.css` (or single file)
- Responsive — works from 320px to 1920px
- Clean, professional design
