# Medium Project 09 — Quasar Admin Dashboard

> **Type:** Medium Project
> **Subject:** Quasar
> **Estimated sell price:** $300–500
> **Difficulty:** Intermediate
> **Prerequisites:** Lessons 01–10 (Quasar basics through API integration)

## Project Brief

Build a modern admin dashboard with Quasar — sidebar navigation, data tables, charts, CRUD modals, and authentication. Admin dashboards are one of the most common freelance projects.

## What you'll build

A Quasar admin dashboard with:
- Login page (mock auth)
- Sidebar navigation (Dashboard, Users, Products, Orders, Settings)
- Dashboard page: stat cards (total users, revenue, orders), simple charts
- Users page: Quasar q-table with pagination, sorting, search, CRUD via dialogs
- Products page: grid view with cards, add/edit dialog
- Settings page: profile settings, dark mode toggle
- Responsive: sidebar collapses to drawer on mobile
- Dark mode support

## Skills you'll demonstrate

- Quasar layout system (q-layout, q-drawer, q-header)
- Quasar q-table (columns, pagination, sorting, filtering)
- Quasar dialogs (q-dialog for CRUD modals)
- Quasar components (q-card, q-chip, q-badge, q-input)
- Pinia for state management (auth, data)
- Vue 3 Composition API
- Responsive design
- Dark mode

## Requirements

- [ ] Login page with username/password (mock auth, no backend needed)
- [ ] Quasar layout with sidebar (q-drawer) and header
- [ ] Sidebar nav: Dashboard, Users, Products, Orders, Settings
- [ ] Dashboard: 4 stat cards + simple bar/line chart (can use a chart library or CSS bars)
- [ ] Users: q-table with columns (name, email, role, status), pagination, sorting, search filter
- [ ] Users: add/edit dialog with form validation
- [ ] Users: delete with confirm dialog
- [ ] Products: card grid view with add/edit dialog
- [ ] Settings: profile form + dark mode toggle
- [ ] Dark mode toggle (Quasar $q.dark.toggle())
- [ ] Responsive: sidebar becomes overlay drawer on mobile
- [ ] Mock data (JSON or hardcoded arrays)
- [ ] Loading states (q-spinner or q-skeleton)
- [ ] Notifications on CRUD actions (Quasar Notify)

## Deliverables

- Complete Quasar project
- Mock data (no backend required)
- README with setup instructions
- Screenshots of all pages
