# Medium Project 01 — Pricing Page with 3 Tiers

> **Type:** Medium Project
> **Subject:** HTML/CSS/JS
> **Estimated sell price:** $200–400
> **Difficulty:** Intermediate
> **Prerequisites:** Lessons 01–10 (HTML + CSS through Flexbox)

## Project Brief

Build a polished pricing page with a monthly/yearly billing toggle, 3 pricing tiers, feature comparison lists, and a FAQ section. This is one of the most common freelance jobs — every SaaS company needs a pricing page.

## What you'll build

- 3 pricing cards (Starter, Pro, Enterprise) side by side
- Monthly/Yearly toggle that changes prices dynamically (JS)
- Feature lists with checkmarks/crosses per tier
- "Most Popular" badge on the middle tier
- FAQ accordion section
- Fully responsive (cards stack on mobile)
- Hover effects on cards

## Skills you'll demonstrate

- CSS Flexbox for card layout
- JavaScript for billing toggle (DOM manipulation)
- CSS transitions for hover effects
- Responsive design with media queries
- Accordion pattern (JS + CSS)

## Requirements

- [ ] 3 pricing cards with: name, price, features list, CTA button
- [ ] Monthly/Yearly toggle (switch UI) that updates all prices
- [ ] Yearly shows discount (e.g., "Save 20%")
- [ ] Middle card highlighted with "Most Popular" badge and different color
- [ ] Feature lists with checkmark (✓) for included, cross (✗) for excluded
- [ ] FAQ section with 5+ questions in accordion format (click to expand)
- [ ] Responsive: cards stack vertically on mobile, side-by-side on desktop
- [ ] Hover effect on cards (slight lift/shadow)
- [ ] Toggle has smooth transition animation
- [ ] Clean, professional design

## Deliverables

- `index.html` + `styles.css` + `script.js`
- Responsive, interactive pricing page
