# Capstone Project 03 — Full-Stack Task Management API

> **Type:** Capstone Project
> **Subject:** Python
> **Estimated sell price:** $500–1500
> **Difficulty:** Advanced
> **Prerequisites:** All 20 Python lessons

## Project Brief

Build a production-ready REST API for a task management system (like a simplified Trello/Todoist backend). This is a sellable product — many startups need a task management backend. The API includes authentication, CRUD operations, data validation, tests, and Docker deployment.

## What you'll build

A FastAPI application with:
- **User authentication** — register, login, JWT tokens
- **Task CRUD** — create, read, update, delete tasks
- **Task categories** — organize tasks by category/project
- **Task priorities** — low, medium, high, urgent
- **Due dates** — tasks can have due dates
- **Filtering & sorting** — filter by status, priority, category; sort by date
- **Pagination** — large task lists are paginated
- **SQLite database** — persistent storage
- **Input validation** — Pydantic models
- **Error handling** — proper HTTP status codes and error messages
- **Tests** — pytest with fixtures and parametrize
- **Docker** — Dockerfile and docker-compose for deployment
- **API documentation** — auto-generated by FastAPI (Swagger UI)

## Skills you'll demonstrate

- FastAPI framework (routes, dependency injection, Pydantic)
- SQLite database (schema, queries, relationships)
- JWT authentication (register, login, token verification)
- REST API design (HTTP methods, status codes, pagination)
- Input validation and error handling
- Testing with pytest (fixtures, parametrize, mocks)
- Docker containerization
- API documentation

## Sellable pitch

> "I'll build you a complete task management API with user authentication, CRUD operations, filtering, pagination, and full test coverage. Includes Docker setup for easy deployment and auto-generated API documentation. Production-ready and scalable."

## Requirements

- [ ] User registration (POST /api/auth/register)
- [ ] User login (POST /api/auth/login) — returns JWT token
- [ ] JWT authentication middleware — protected routes require token
- [ ] Create task (POST /api/tasks) — requires auth
- [ ] Get all tasks (GET /api/tasks) — with filtering, sorting, pagination
- [ ] Get single task (GET /api/tasks/{id})
- [ ] Update task (PUT /api/tasks/{id})
- [ ] Delete task (DELETE /api/tasks/{id})
- [ ] Tasks have: title, description, status (todo/in_progress/done), priority, category, due_date
- [ ] Input validation with Pydantic models
- [ ] Proper HTTP status codes (200, 201, 400, 401, 404, 500)
- [ ] Error messages are descriptive and consistent
- [ ] SQLite database with proper schema (users table, tasks table)
- [ ] Tests for all endpoints (pytest with TestClient)
- [ ] Tests for auth flow (register, login, protected route)
- [ ] Dockerfile for the app
- [ ] docker-compose.yml with app + volume for database
- [ ] README with setup, run, and test instructions
- [ ] Environment variables for config (SECRET_KEY, DATABASE_URL)

## Getting started

1. Design the API endpoints and data models.
2. Set up FastAPI project structure (main.py, routers/, models/, tests/).
3. Create SQLite database schema (users, tasks).
4. Implement user registration and login with JWT.
5. Implement task CRUD endpoints.
6. Add filtering, sorting, and pagination.
7. Add input validation and error handling.
8. Write tests for all endpoints.
9. Create Dockerfile and docker-compose.yml.
10. Write README with documentation.
