# Lesson 09 — Coding Check

## Easy

### p01-solve.html — Three color format boxes
- [ ] Three boxes displayed side by side (use flexbox or inline-block)
- [ ] Box 1 uses hex color (`#ff0000` or similar)
- [ ] Box 2 uses rgb color (`rgb(0, 255, 0)` or similar)
- [ ] Box 3 uses hsl color (`hsl(240, 100%, 50%)` or similar)
- [ ] Each box has visible dimensions (width, height, padding)

### p02-solve.html — Card with background image
- [ ] Card has a background image (placeholder URL or local)
- [ ] Uses `background-size: cover`
- [ ] Semi-transparent overlay using rgba (not opacity)
- [ ] Text is readable over the image

### p03-solve.html — Buttons with shadows
- [ ] Three buttons with different shadow depths
- [ ] Subtle shadow: small blur, low opacity
- [ ] Medium shadow: moderate blur and opacity
- [ ] Strong shadow: large blur, higher opacity
- [ ] Hover effect increases shadow on all buttons

## Medium

### p01-solve.html — Hero with gradient
- [ ] Full-width hero section
- [ ] Linear gradient with 3 colors
- [ ] Centered white text
- [ ] text-shadow on the text for readability
- [ ] CTA button with its own style

### p02-solve.html — Card grid with hover
- [ ] 3 cards in a grid (flexbox or grid)
- [ ] Each card has a background image
- [ ] Gradient overlay appears on hover
- [ ] box-shadow on cards
- [ ] Rounded corners (border-radius)
- [ ] Title and description in each card

### p03-solve.html — Color palette display
- [ ] 5 color swatches displayed
- [ ] Each swatch shows hex, rgb, and hsl values
- [ ] CSS variables used for colors (`:root` or `--var`)
- [ ] Text on each swatch has sufficient contrast (4.5:1 minimum)

## Hard

### p01-solve.html — Glassmorphism card
- [ ] Semi-transparent background (`rgba` or `hsla`)
- [ ] `backdrop-filter: blur()` effect
- [ ] Subtle border (1px solid rgba)
- [ ] box-shadow for depth
- [ ] Placed over a gradient background (to show the blur effect)

### p02-solve.html — Profile card
- [ ] Avatar using radial gradient (no image file)
- [ ] Name, bio, and stats row (3 stats)
- [ ] Follow button with hover effect
- [ ] box-shadow for card elevation
- [ ] Gradient accents for visual interest
- [ ] Smooth hover transitions

### p03-solve.html — Animated landing hero
- [ ] Animated gradient background (CSS `@keyframes` shifting background-position)
- [ ] Floating cards with box-shadow
- [ ] Glassmorphism navbar (semi-transparent + blur)
- [ ] Gradient text effect (`background-clip: text`)
- [ ] All elements visually cohesive
