# Level 01 — ML Foundations

> **Math level:** 10th grade is enough. See [MATH-YOU-NEED.md](../MATH-YOU-NEED.md) — it explains every symbol used here.

## What You'll Learn
- What machine learning actually is (vs traditional programming)
- The three types: supervised, unsupervised, reinforcement
- How to recognize which type a problem belongs to
- The ML pipeline from data to deployment

## Prerequisites
- Basic Python (variables, functions, lists, dicts)
- No ML experience needed

## Time Estimate
- 2-3 hours for all problems + project

---

## How This Level Works

Each problem has:
1. **CONCEPT** — the idea you need to understand
2. **PROBLEM** — what to build
3. **TRY THIS INPUT** — test code to verify your solution
4. **EXPECTED OUTPUT** — what it should print
5. **AUTO-CHECK** — run `check.py` to verify automatically

Start with `easy/` problems, then `medium/`, then `hard/`, then the project.

---

## Problems

### Easy
1. `easy/p01-classify-type.py` — Classify scenarios as supervised/unsupervised
2. `easy/p02-features-labels.py` — Identify features (X) and label (y)
3. `easy/p03-traditional-vs-ml.py` — Choose traditional vs ML approach

### Medium
4. `medium/p01-design-spam.py` — Design a spam classifier system
5. `medium/p02-train-test.py` — Explain train/test splits
6. `medium/p03-match-algorithm.py` — Match algorithms to problems

### Hard
7. `hard/p01-ml-pipeline.py` — Design a complete ML pipeline
8. `hard/p02-confusion-matrix.py` — Calculate TP/FP/TN/FN
9. `hard/p03-bias-variance.py` — Explain bias-variance tradeoff

### Project
`project/` — Apply everything to design a real ML system

## Verify Your Work

```bash
# Run a problem
python3 easy/p01-classify-type.py

# Check your answer
python3 check.py easy/p01
```

When `check.py` says "PASS", add `# DONE` to the first line of your file and move on.
