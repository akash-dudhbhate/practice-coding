# Lesson 18 — Coding Check

## Easy

### p01-solve.jsx — Card component
- [ ] White background (`bg-white`)
- [ ] Rounded corners (`rounded-lg`)
- [ ] Shadow (`shadow-md`)
- [ ] Padding (`p-6`)
- [ ] Title, description, and button included
- [ ] Visually appealing

### p02-solve.jsx — Responsive grid
- [ ] 1 column on mobile (`grid-cols-1`)
- [ ] 2 columns on tablet (`md:grid-cols-2`)
- [ ] 3 columns on desktop (`lg:grid-cols-3`)
- [ ] Gap between items (`gap-4`)
- [ ] Each cell has content

### p03-solve.jsx — Button with states
- [ ] Hover state changes color (`hover:bg-...`)
- [ ] Focus state shows ring (`focus:ring-2`)
- [ ] Active state scales down (`active:scale-95`)
- [ ] Transition applied (`transition-colors` or `transition-all`)
- [ ] All states visible in browser

## Medium

- [ ] 3 variants: primary, secondary, danger
- [ ] 3 sizes: sm, md, lg
- [ ] `className` prop accepted for customization
- [ ] Variants have correct colors and hover states
- [ ] Sizes have correct padding and font size

### p02-solve.jsx — Responsive navbar
- [ ] Logo on the left
- [ ] Links on the right (hidden on mobile)
- [ ] `hidden md:flex` for desktop links
- [ ] Hamburger menu on mobile (`md:hidden`)
- [ ] Navbar is responsive
- [ ] Layout doesn't break at any size

### p03-solve.jsx — Styled form
- [ ] Text, email, password inputs styled
- [ ] Select dropdown styled
- [ ] Checkbox styled
- [ ] Focus states (ring or border color)
- [ ] Error states (red border + error message)
- [ ] Labels for each field
- [ ] Consistent styling across all inputs
